# 🎓 The Dropout Signal

Welcome to **The Dropout Signal**! This is a fair early-warning machine learning system built to predict student dropout risk. It gives academic advisors clear, actionable insights to help struggling students.

## 🚀 Key Features

*   **Risk Intelligence Dashboard**: Real-time aggregated stats, risk distribution, and performance metrics.
*   **Red Zone Explorer**: Proactive intersectional detection targeting students with low engagement/sentiment and high financial stress.
*   **Explainable AI (SHAP)**: Plain-English explanations breaking down the exact factors driving a student's risk profile.
*   **Prescriptive Action Plans**: Advisor-focused recommended interventions based on individual student risk signals.
*   **Algorithmic Fairness Audits**: Real-time evaluation of marginal and intersectional disparities (Demographic Parity & Equal Opportunity).
*   **Bias Mitigation**: In-processing fairness constraints to reduce algorithmic bias while maintaining high classification accuracy.
*   **What-If Scenario Simulator**: Policy planning playground to simulate socioeconomic and academic relief measures in real-time.

## 💻 Running the Project Locally

To run the full-stack application on your machine:

### 1. Setup the Environment
Make sure you have your virtual environment activated:
```bash
# Windows PowerShell:
.\venv\Scripts\Activate.ps1

# Windows CMD:
.\venv\Scripts\activate.bat
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the App
```bash
python app.py
```

Open your browser and navigate to **`http://localhost:5050`** to view the live dashboard!
